    方法A　Claudeの会話に登記を貼って、返ってきたJSONをここに貼るキー不要・無料

    Claudeの会話に登記のPDFを添付して、下の一文をそのまま送ってください。返ってきたJSONをこの欄に貼って「取り込む」、またはファイルでもらったなら「JSONファイルを選ぶ」。どちらでも物件情報・土地・建物が一括で入ります。周辺物件リストのJSONも、保存した査定データも、同じ場所で取り込めます。

    前置きの文章が混じっていても、JSONの部分だけ拾います。
    方法B　APIキーを入れて、このファイルから直接読み取る

    platform.claude.com の Settings → API keys で発行します。claude.ai の月額プランとは別の従量課金なので、先にクレジットカードの登録が必要です。
    キーを入れても、ファイルを直接開いた状態（アドレスが file:／C:\ で始まる）では通信がブロックされることがあります。その場合はフォルダで python -m http.server を実行し、http://localhost:8000/ から開いてください。

    3建物査定単価・グレード・耐用年数は自動判定

    評価の方針

    法定耐用年数を超えた建物に価値を付けるかどうかの目安です。これを超える建物には、チェック欄で「価値なし」を提案します。空欄にすると提案しません。

    駐車スペース

    駐車場の補正率には公表された基準がありません。不足1台あたりの120万円は、近隣の月極5,000円を年額換算し利回り5％で割り戻した目安です。舗装工事費は見積り額を入れてください（空欄なら減価しません）。

    4諸費用・控除入力すると査定書に項目が増えます

    解体処分費「価値なし」にした建物が対象
    残置物処分費家財・什器の撤去

    金額はプラスで入力してください。査定額からは自動で差し引かれます。解体単価・残置物単価は御社の実績を入れてください。自動計算は「対象の延床面積 × 単価」です。現地を見て一式で見積もる場合は「金額を手入力」に切り替えてください。残置物の対象面積は、価値なしの建物があればその延床、無ければ建物全体の延床です。

    仲介手数料仲介で売却する場合

    内訳を出したくない場合はチェックを外してください。査定額には反映されますが、査定書には内訳が出ません。
